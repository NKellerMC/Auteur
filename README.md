<h1 align="center">Auteur</h1>

Copyright © 2026 Noah Keller

Auteur is a Minecraft mod which allows you to record your Minecraft gameplay, play it back and create cinematic stories, camera movements and replay sequences.

## Features

- Replay Recording
- Replay Playback
- Camera Paths
- Keyframes
- Timeline Editing
- Cinematic Tools

## How to install

1. Install Fabric Loader (https://fabricmc.net/use/installer/)
2. Install Fabric API (https://modrinth.com/mod/fabric-api)
3. Download Auteur from Modrinth
4. Place Auteur and Fabric API into your mods folder (`.minecraft/mods`)
5. Run the game

## Current Status

Auteur is currently in active alpha development.

Current alpha features include:

- Replay recording
- Start/stop recording keybind
- `.auteur` replay format
- Core recording system

Many planned features are still under development.
