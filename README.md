# Auteur

A cinematic replay and storytelling tool for Minecraft.

Auteur is designed for creators, filmmakers and storytellers who want complete control over how their Minecraft worlds are captured and presented.

## Features

- 🎬 Replay Recording
- 📷 Camera Paths
- 🔑 Keyframes
- 🎞️ Timeline Editing
- ✨ Cinematic Tools

## Status


Current Alpha Features:

- Replay recording
- Start/stop recording keybind
- `.auteur` replay format
- Core recording pipeline

## Vision

Minecraft is more than a game.

It's a platform for stories, films, documentaries and creativity.

Auteur aims to provide the tools needed to bring those stories to life.
